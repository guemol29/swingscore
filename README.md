# Swing Score

Aplicació web Streamlit del motor Swing Score.

## Funcions
- Tickers manuals
- Importació CSV de Watchlist Yahoo Finance
- Score / etiqueta / Stage 2 / Acció
- Fiabilitat històrica 20d només per Stage 2
- Descàrregues Yahoo Finance agrupades i cachejades per accelerar l’anàlisi

## Execució local
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Desplegament
Pujar `streamlit_app.py`, `swing_engine.py` i `requirements.txt` a un repositori GitHub i desplegar-lo a Streamlit Community Cloud.
